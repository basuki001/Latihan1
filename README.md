# Starter — Landing Page

Landing page modern dan responsive untuk produk digital / SaaS, dibuat dengan HTML & CSS murni tanpa dependency eksternal.

![CSS](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)

## Preview

Buka `index2.html` di browser untuk melihat hasilnya.

## Fitur

- **Single file** — semua HTML, CSS, dan JS dalam satu file, tanpa build tools
- **Responsive** — tampilan optimal di desktop, tablet, dan mobile
- **Smooth scroll** — navigasi halus antar section
- **Mobile menu** — hamburger menu untuk layar kecil
- **Accessible** — semantic HTML, ARIA labels, dan keyboard-friendly

## Struktur Halaman

| Section | Deskripsi |
|---------|-----------|
| Navbar | Fixed navigation bar dengan blur effect |
| Hero | Headline utama, deskripsi, dan CTA buttons |
| Fitur | 6 kartu fitur unggulan dengan hover effect |
| Statistik | Angka pencapaian (pengguna, uptime, dll) |
| Pricing | 3 paket harga: Gratis, Pro, Enterprise |
| Testimoni | 3 review dari pengguna |
| CTA | Call-to-action untuk konversi |
| Footer | Logo, link, dan copyright |

## Cara Pakai

1. Clone atau download repository ini
2. Buka `index2.html` di browser
3. Edit konten sesuai kebutuhan

## Kustomisasi

Warna utama menggunakan **Indigo** (`#6366f1`). Untuk mengganti tema warna, cari dan replace nilai hex berikut di file HTML:

| Variabel | Nilai | Kegunaan |
|----------|-------|----------|
| Primary | `#6366f1` | Warna utama (tombol, aksen) |
| Primary hover | `#4f46e5` | Hover state |
| Primary light | `#eef2ff`, `#e0e7ff`, `#c7d2fe`, `#a5b4fc` | Background, gradient |
| Text dark | `#1e293b` | Teks utama |
| Text muted | `#64748b`, `#475569` | Teks sekunder |
